## 03 // Flagship System — Synapse Atlas

### 🧠 [Synapse Atlas](https://github.com/tahmidd01/Synapse-Atlas)

**Neuro-Symbolic Multimodal AI for Interpretable Depression Screening with Proxy Anxiety and Psychological Distress Indicators**

My five-member FYDP team built a **local-first research platform** designed to make model reasoning inspectable rather than hiding it behind a single opaque mental-health score.

- Eight supervised **ordinal PHQ-8 symptom concepts** form the primary path to the total score.
- **MentalRoBERTa** provides the retained text representation; symbolic rules compute the total, severity band, and research screening flag.
- **Whisper / WavLM** support audio and video workflows without silently overriding the text-primary PHQ path.
- Separate proxy-anxiety and trauma-related distress pathways remain explicitly bounded.
- **Synapse Guide** uses a local **Qwen3 4B + llama.cpp** assistant with curated retrieval and structured result context.
- Includes concept intervention, provenance-aware evidence exploration, uncertainty display, local operation, and post-evaluation QA.

| Frozen evaluation / QA | Result |
|---|---:|
| Official frozen TEST sessions | **56** |
| RMSE | **4.8885** |
| MAE | **3.9894** |
| Positive F1 | **0.6500** |
| PR-AUC | **0.7215** |
| Guarded software tests | **148** |
| Responsive size/theme QA combinations | **24** |

## 07 // How I Build

```text
01  Frame the real problem before choosing the technology.
02  Make data lineage, assumptions, and evaluation boundaries explicit.
03  Separate research evidence from demo behavior and product polish.
04  Build end-to-end: UI → API → persistence → intelligence → evaluation.
05  Prefer inspectable logic when black-box complexity is not justified.
06  Test failure paths, not only the happy path.
07  Treat accessibility, privacy, and documentation as engineering work.
08  Ship something a human can understand, operate, and critique.
```
